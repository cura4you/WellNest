# Care petals · round two

The user selected option 06 from the first logo board. This review page explores eight refinements of that direction and four wordmark treatments. The live application logo remains unchanged while a final choice is pending.

[Open the comparison](https://medivault-roan-six.vercel.app/care-petals/index.html)

Shapes: P1 Balanced petals; P2 Softer curves; P3 Open center; P4 Rounded clover; P5 Leaf fold; P6 Outlined petals; P7 Quiet twist; P8 Tonal petals.

Wordmarks: W1 Modern; W2 Soft; W3 Editorial; W4 Lowercase. The wordmark previews update to the selected petal shape. Four palettes and a dark background are available. SVG downloads reflect the current shape, type, palette and background treatment. Separate base SVGs live beside the review HTML.

Contact sheets: shapes.png and wordmarks.png. The standalone page is in public/care-petals/index.html; it is separate from the React application.

Headless Chromium checks covered all eight shape selections, four wordmark choices, four palettes, the dark-background toggle, preview/download correspondence, SVG text treatments, and unclipped layouts at 320, 390, 768, 1320 and 1600 pixels. No backend services or account data are involved in this design review.
